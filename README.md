# Rick and Morty API - Java

Aplicación desarrollada en Java que consume la API pública de Rick and Morty.

## ¿Qué hace?
- Consume la API REST de Rick and Morty
- Procesa y muestra información de personajes
- Manejo de peticiones HTTP y respuestas JSON

## Tecnologías
- Java
- API REST
- JSON

## API utilizada
[The Rick and Morty API](https://rickandmortyapi.com/)
